# Coarse-Graining and Long-Range Response in Generated Systems

Author: [Jinku Guo](https://orcid.org/0009-0000-6600-6171)

Work type: Research article

Repository snapshot: [21 October 2026](https://github.com/bookwormseagull1980/Book-and-Articles/tree/coarse-graining-and-long-range-response-in-generated-systems-2026-10-21/articles/coarse-graining-and-long-range-response)

## Abstract

We study when a reduced description preserves the strength and singularities of
the response to an applied source. For systems defined by state updates and
observations, eliminating variables changes the feedback, source coupling, readout
and direct response together. For jointly C¹ updates and observations and bounded
surjective linear coarse maps between Banach spaces, fibre consistency yields
differentiable descent of the update and observation, and hence preservation of
their joint source response on the common invertible domain. For approximate
descent, we derive an exact response-error identity that separates defects in the
update, source, readout and direct term without requiring an inverse coarse map.
Resolvent and contour estimates propagate reference-branch, source and readout
errors to visible poles and their residues at displaced critical points. In a
reciprocal Hilbert-space realisation with a self-adjoint endpoint operator, an
isolated finite-dimensional critical subspace, a bounded complementary inverse and
a positive crossing matrix, the visible residue is positive semidefinite and
finite rank; source overlap determines which critical directions remain visible.
Arithmetic and reflecting-heat examples distinguish static response preservation
from memoryless dynamical closure. In the two-mode example, at fixed geometric
memory decay 0<d<1, retaining m terms gives pole displacement O(d^m) and residue
error O(md^m). In a vacuum quantum-field-theory realisation, when the exact
unfiltered-covariance, projection, source-pairing, continuation, subtraction and
endpoint matching hypotheses hold, the response residue is the zero-mass atom of
the corresponding positive spectral measure.

## Keywords

Coarse-graining; Generated systems; Model reduction; Linear response; Schur complements; Memory kernels; Analytic Fredholm theory; Spectral residues; Operator approximation.

## Scope

The central object is the complete source-to-observation response. Static response
preservation and memoryless dynamical closure are distinct requirements. The pole
and residue estimates compare specified branches near isolated critical points
under the stated resolvent and crossing bounds.
