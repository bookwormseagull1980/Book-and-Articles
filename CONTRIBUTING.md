# Scientific feedback and corrections

This repository welcomes precise questions about the construction and its results.
Use [Discussions](https://github.com/bookwormseagull1980/Book-and-Articles/discussions)
for mathematical interpretation, physical mechanisms and reading questions.
Use an issue for a specific textual correction, failed reproduction or discrepancy
between a published statement and its implementation.

A useful correction identifies the work or declaration, the relevant passage,
and the reason for the proposed change. A reproduction report identifies the
source revision, command, environment and affected output. Numerical enclosure,
regression-test success and agreement with observations are distinct results;
state which one the report concerns.

Please keep evidence, calculations and proposed changes together. Existing
archives and release tags identify earlier scientific records and remain
unchanged. See the repository's citation guidance and license or per-work
rights statements before redistributing material.
