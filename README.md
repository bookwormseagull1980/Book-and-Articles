## Archival Policy

The repository is a catalogue, not a single citable publication. Each book or
article is maintained as a distinct work. A work's directory records its own
persistent identifiers and checksum. Zenodo records are maintained per work and
linked to title-based immutable Git tags. A Zenodo concept DOI identifies the
evolving work; a Zenodo version DOI identifies one immutable deposited version.
